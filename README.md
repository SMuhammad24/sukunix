# Sukunix.com - Enterprise Software Engineering & IT Solutions

> Professional, high-performance, and responsive website for **Sukunix** (`sukunix.com`), built with clean semantic HTML5, modern CSS3 design system, and Vanilla JavaScript.

🌐 **Live GitHub Pages URL**: [https://smuhammad24.github.io/sukunix/](https://smuhammad24.github.io/sukunix/)

---

## 🚀 Key Features

- **Enterprise Aesthetic & Design System**: Crisp, authoritative aesthetic engineered for trust, performance, and cross-device responsiveness.
- **Interactive Project Scope & Cost Estimator**:
  - Live calculations for web applications, mobile platforms, data systems, and cloud infrastructure.
  - Transparent timeline and investment breakdown.
  - One-click transfer to pre-fill the consultation inquiry form.
- **Architecture Discovery Consultation System**:
  - Dynamic 14-day business date slot selector with executive time slots.
  - Multi-timezone support (IST, EST, GMT, GST, SGT).
  - Instant Zoom meeting credentials generation with one-click direct join.
  - Automated `.ics` calendar invite download.
  - Instant WhatsApp direct message routing.
- **Filterable Case Studies**:
  - Showcases for FinTech, AI/Analytics, Cloud Migration, and HealthTech engagements with verified metrics.
- **Structured 5-Step Delivery Methodology & Modern Tech Matrix**:
  - Clear workflow from Discovery to Production deployment.
  - Comprehensive engineering stack (React, Node.js, Go, PostgreSQL, AWS, Kubernetes).
- **Direct Consultation Form**:
  - Client-side validation with clean notification feedback.
- **Zero Heavy Dependencies**:
  - Fast, accessible, and ultra-lightweight static site.

## 🌐 Deployment to GitHub Pages

This repository is configured to deploy directly to GitHub Pages from the `main` branch:
1. Push to `main`.
2. In GitHub Repository Settings -> Pages, select Source: `Deploy from a branch` -> `main` / `/(root)`.
